# Project notes

This project is a standalone React + Vite storefront and admin dashboard for an interior design and material showroom.

## Local workflow

- Install dependencies with `npm install`
- Start the app with `npm run dev`
- Build for production with `npm run build`

## Project structure

- `src/pages` for public and admin screens
- `src/components` for reusable layout and UI elements
- `src/services` for mock app data access
- `src/lib` for shared utilities and configuration

Keep changes focused on the product itself and avoid adding platform-specific scaffolding.
